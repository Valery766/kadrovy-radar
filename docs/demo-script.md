# Сценарий демонстрации (5 минут) и вопросы жюри

## Демо (в MAX, с телефона или web.max.ru)
1. **0:00** Открываем `@t796_hakaton_max_bot` → «Начать». Одна фраза: «Ставка — зарплатный радар: сколько платят конкуренты вашего размера, где ваша ставка на шкале рынка».
2. **0:30** «Ввести ИНН» → `7801633015` → профиль из реестра МСП: ООО «Малый 43», микропредприятие, ОКВЭД 56.10, Санкт-Петербург. Подчеркнуть бейдж «ФНС · получено сегодня».
3. **1:00** «Верно, дальше» → «Повар» → `45000` → карточка: 22-й перцентиль, медиана 65 000 ₽, микропредприятия — 80 000 ₽, выборка 258/234 из 702. Пояснить: дубли и объявления сверх лимита на работодателя убраны, размер работодателя — из реестра МСП.
4. **2:00** «Открыть радар» → шкала, гистограмма, варианты ставки, категории работодателей, типичные вакансии, источники с датой.
5. **2:45** «Отправить PDF-отчёт в чат» → PDF в чате → «Поделиться отчётом в MAX» → выбираем чат совладельца → отчёт переслан (бонус MAX).
6. **3:30** В чате: голосование «Медиана 66 т.», «Следить за рынком», «Текст вакансии» → черновик из частых формулировок.
7. **4:15** Масштабирование: `/profile` → `1601000159` (Агрызское райпо, Татарстан, розница) → «Продавец» → `35000` — тот же код, другой пакет контекста. Показать `packs/tatarstan-roznitsa.yaml` и `git diff --stat` (ядро не тронуто).
8. **4:45** Резюме: два живых госисточника, детерминированный расчёт, честная выборка, бонус доведён до результата.

## Вопросы, которых ждём
- **«Госпортал не весь рынок»** — да: показываем заявленные ставки и размер выборки; главная ценность — срез по размеру работодателя; следующий шаг — второй источник (hh.ru по договору).
- **«Медиана ниже реальной»** — поэтому даём распределение и «верхнюю четверть», а не одно число; наблюдаем закрытие вакансий выше/ниже медианы.
- **«Это калькулятор, который гуглится»** — за 10 минут на job-бордах не получить срез «микропредприятия vs бюджет» и распределение по 234 работодателям; у нас это 30 секунд в мессенджере плюс отчёт партнёру.
- **«Почему без LLM?»** — п. 9.5 правил и принцип кейса: факты/расчёты/рекомендации разделены, каждое число выводимо; LLM можно добавить как объяснительный слой, не как источник результата.
- **«Как масштабируется?»** — YAML-пакеты: регион 0 ч, отрасль 1 ч, источник 1–2 дня; универсальный пакет уже покрывает 91 регион.
- **«Персональные данные?»** — ИНН ИП: храним только ИНН и публичные поля реестра, не логируем, не связываем с телефоном; отчёты только в личный чат пользователя.
- **«Что если API упадёт?»** — кэш 6 часов, деградация с пометкой даты, «Повторить» без перезапуска сценария; сторож вебхука.
