# Словарь простых формулировок «Кадрового радара»

Правило продукта: пользователь не должен думать. Каждое число сопровождается словами, что оно значит для него, и подсказкой, что делать дальше. Термины ниже в текстах бота, мини-приложения и PDF заменяются на объяснение из правой колонки. Термин в скобках можно оставить мелким шрифтом один раз, для тех, кто его знает.

## Правила текста

- Никаких длинных тире «–». Только среднее тире «–» с пробелами или обычное предложение.
- Короткие предложения. Одно число – одно предложение. Сначала вывод, потом откуда он взялся.
- Каждый экран и каждое сообщение бота заканчиваются блоком «Что дальше» с кнопками.
- Числа денег с пробелами и знаком ₽: 65 000 ₽. Доли в процентах: 75 %.
- Источник и дата у каждого блока: «По данным «Работы России» на 23.09».

## Путеводитель при первом запуске (бот, после приветствия)

Пользователь с первого экрана должен понять, что умеет бот и с чего начать. После приветствия бот присылает короткий путеводитель:

1. Сколько платить – проверить ставку по должности и региону. Начните с этого: /stavka.
2. Найти людей – опубликовать вакансию со ссылкой и QR, получать отклики прямо в MAX: кнопка под карточкой ставки, затем /vacancies.
3. Проверить свой штат – кто из сотрудников получает меньше рынка и сколько стоит это исправить: /staff.
4. Сравнить регионы и увидеть весь рынок региона: /regions, /digest.
5. Узнать о плановых проверках трудовой инспекции и Роспотребнадзора по вашему ИНН: /checks.

Путеводитель повторяется по команде /help и доступен кнопкой «Что умеет бот» под приветствием.

## Структура любого ответа с цифрами

1. Вывод одной фразой простыми словами.
2. Два-три числа с объяснением каждого.
3. «Что это значит для вас» – одна-две фразы.
4. «Что дальше» – кнопки.
5. Источник и дата.
