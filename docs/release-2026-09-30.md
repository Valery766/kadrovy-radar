# Конкурсный выпуск 30.09.2026

Команда unecon.tech. Кадровый радар, трек «Эффективный бизнес».

## Изменения

- Кабинет работодателя возвращает до 500 собственных вакансий, чтобы объявления с откликами не пропадали за первыми 50 записями.
- Поиск каталога явно подписан как поиск по должности или работодателю. Пустая выдача предлагает изменить фильтры.
- Повторный импорт учебного каталога сохраняет реальные отклики и состояние связанных вакансий. На рабочем сервере импорт при выпуске не выполняется.
- Добавлены OpenAPI 3.1, DATA-API.yaml и тестовые параметры. API мини-приложения включено в технический контур сдачи.

## Проверка
