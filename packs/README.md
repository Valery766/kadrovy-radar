# Пакеты контекста (переменная часть)

Ядро «Ставки» (`server/src/core`) не содержит ни одного упоминания региона, отрасли или профессии.
Всё, что зависит от контекста, лежит здесь в декларативных YAML-файлах:

| Файл | Что описывает |
|---|---|
| `_shared/professions.yaml` | Каталог профессий: как искать в источнике, какие названия считать этой профессией, какие исключать |
| `_shared/phrases.yaml` | Словарь формулировок требований (медкнижка, опыт, график…) для частотного разбора |
| `_shared/regions.json` | Справочник регионов «Работы России» (код, код ФНС, название, средняя зарплата) |
| `<регион>-<отрасль>.yaml` | Пакет контекста: регион, отрасль по ОКВЭД, набор профессий, пороги достоверности, шаблон условий вакансии, демо-пример |
| `_generic.yaml` | Универсальный пакет: любой регион из профиля бизнеса, полный каталог профессий |

Пакет выбирается автоматически по профилю бизнеса из реестра МСП (регион + ОКВЭД):
точное совпадение регион+отрасль → совпадение по региону → универсальный пакет.

Новый регион или отрасль = новый YAML-файл, без изменения кода. Проверка: `npm run packs:validate`.
