# Пакеты контекста (переменная часть)

Ядро «Ставки» (`server/src/core`) не содержит ни одного упоминания региона, отрасли или профессии.
Всё, что зависит от контекста, лежит здесь в декларативных YAML-файлах:

| Файл | Что описывает |
|---|---|
| `_shared/professions.yaml` | Каталог профессий: как искать в источнике, какие названия считать этой профессией, какие исключать |
| `_shared/phrases.yaml` | Словарь формулировок требований (медкнижка, опыт, график…) для частотного разбора |
| `_shared/regions.json` | Справочник регионов «Работы России» (код, код ФНС, название, средняя зарплата, безработица) |
| `_shared/okpdtr.json` | Справочник ОКПДТР «Работы России»: 8 037 активных позиций `{code, name}` для подсказок по свободному вводу должности (локальная копия, без запросов в рантайме) |
| `<регион>-<отрасль>.yaml` | Пакет контекста: регион, отрасль по ОКВЭД, набор профессий, пороги достоверности, шаблон условий вакансии, демо-пример |
| `_generic.yaml` | Универсальный пакет: любой регион из профиля бизнеса, полный каталог профессий |

Сейчас в наборе четыре пакета: `spb-obschepit` (Общепит · Санкт-Петербург), `tatarstan-roznitsa`
(Розница · Республика Татарстан), `apk-sezon` (АПК · сезонные работы, Краснодарский край) и `_generic`.

Пакет выбирается автоматически по профилю бизнеса из реестра МСП (регион + ОКВЭД):
точное совпадение регион+отрасль → совпадение по региону → универсальный пакет.

Новый регион или отрасль = новый YAML-файл, без изменения кода. Проверка: `npm run packs:validate`.

## Свободный ввод должности

Каталог из 18 отобранных профессий — это кнопки и качественные синонимы. Всё остальное
закрывает свободный ввод: `resolveProfession(catalog, pack, text)` сначала ищет профессию
пакета и каталога (по названию и синонимам), а если не нашёл — собирает «свою» профессию
с ключом `custom:<slug>`, где slug детерминированно выводится из текста. Ядро работает
с такой профессией так же, как с каталожной; кэш вакансий и так ведётся по тексту запроса.

Подсказки при вводе даёт `suggestProfessions(catalog, text, limit)`: сначала профессии
каталога, затем позиции ОКПДТР из `_shared/okpdtr.json`. Внешних запросов при подсказке нет.

## Пакет `apk-sezon`: как выбирались профессии

Регион — Краснодарский край (код ФНС `23`, код «Работы России» `2300000000000`), отрасль —
ОКВЭД `01` (растениеводство и животноводство). В пакет попали только профессии, по которым
источник реально отдаёт выборку. Объёмы проверены живыми запросами 23.09.2026
(`/api/v1/vacancies/region/2300000000000?text=<профессия>&limit=1` → `meta.total`):

| Профессия | Вакансий по региону | В пакете |
|---|---|---|
| водитель | 924 | да |
| подсобный рабочий | 467 | да |
| тракторист | 335 | да |
| грузчик | 201 | да |
| упаковщик | 180 | да |
| ветеринар | 88 | нет — меньше 100 |
| агроном | 65 | нет — меньше 100 |
| животновод | 34 | нет |
| садовод | 21 | нет |
| овощевод | 17 | нет |
| механизатор | 5 | нет |
| птицевод / доярка | 3 / 1 | нет |

Для сравнения: в Ростовской области (`61`) те же запросы дают в 2–3 раза меньше
(тракторист 128, агроном 26, животновод 6), поэтому демо-регион — Краснодарский край.

Демо-предприятие пакета — **ООО «Владимирское», ИНН `2377001795`**: микропредприятие
реестра МСП, ОКВЭД 01.25 («Выращивание прочих плодовых деревьев, кустарников и орехов»),
Лабинский район Краснодарского края, юрлицо, запись активна. Оно публиковало вакансию
тракториста в июле 2026 — сезонный набор виден прямо в датах публикации.
